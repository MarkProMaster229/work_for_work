# КосмоХакатон 2026 — Проектирование устойчивой спутниковой группировки

Веб-сервис для проектирования спутниковой группировки и оценки доступности связи в северных районах.

## Что делает сервис

- Загружает сценарий спутниковой группировки.
- Считает положение спутников, видимость наземных пунктов и межспутниковые связи.
- Строит маршруты от клиентских пунктов до шлюза через спутниковую сеть.
- Оценивает доступность связи, продолжительность перерывов и характеристики маршрутов.
- Показывает причины отсутствия маршрута.
- Позволяет сохранять и сравнивать варианты конфигурации.
- Выгружает результаты в формате `cosmo-A-result-1.0`.

## API endpoints

Healthcheck:
  GET /api/health

Сценарий:
  POST /api/scenario/load
  POST /api/scenario/export

Наземные пункты:
  GET /api/ground_sites

Спутники и маршруты:
  GET /api/satellites?t_s=X
  GET /api/routes?t_s=X
  POST /api/routes
  GET /api/snapshot?t_s=X
  POST /api/snapshot

Расчёт:
  POST /api/calculate
  POST /api/export

Варианты:
  POST /api/variants/save
  GET /api/variants
  DELETE /api/variants/<name>
  POST /api/variants/compare


## Результаты анализа

Сравнение 4 сценариев:

  Сценарий                    C65      C70      C72
  Полная группировка          96.67%   98.75%   98.89%
  Первая очередь              27.22%   15.83%   12.64%
  Отказы 10 спутников         79.31%   80.97%   82.64%
  ISL 2000 км                 83.61%   73.19%   75.28%

Целевой ориентир: 90%.
Вывод: только полная группировка даёт >90% для всех клиентов.

## Устойчивость к отказам

Отказ одного спутника:
  Разброс от -1.34% (S40) до -2.09% (S02).
  Все клиенты остаются выше 90%.
  Вывод: нет критичных одиночных спутников.

Зависимость от числа отказов:
  1 отказ   -> -2%   -> 96%
  5 отказов -> -10%  -> 88%
  10        -> -22%  -> 76%
  15        -> -35%  -> 63%
  20        -> -49%  -> 49%
  32        -> -80%  -> 18%

Вывод: до 3-5 отказов система держится выше 90%.

Отказ плоскости (16 спутников): -35%.
Эквивалентно потере 15 случайных спутников.


## Рекомендации

1. Полная группировка обязательна.
2. На раннем этапе доступность падает в 5-7 раз.
3. При отказах система держится до 3-5 спутников.
